# Responsible AI

The production authority is deterministic. Validation criteria, pass/fail findings, severity, safety classification, evidence, penalties, and acceptance tests are owned by reviewed code and policy data. No external AI service, API key, internet connection, or model download is required.

The semantic adapter is optional and disabled. A future locally cached model may assist with synonym or similarity candidates, but deterministic logic must independently accept any signal. Any generated wording/advice must be labelled **unverified**. AI output cannot modify rules or execute/rewrite operational commands.
